# AI API コストメーター

**claude.ai や gemini.google.com のWebアプリでチャットしたとき、「もしこれをAPIで払っていたらいくら相当か」を換算して見せる**Chrome拡張機能です。ページの右下に換算メーターが常時表示され、ツールバーのバッジにも今日の合計が出るので、"タダだと思って使いすぎる"のを防ぐ緊張感が持てます。

## インストール(開発者モードで読み込み)

1. このフォルダ(`api-cost-meter`)をPCの好きな場所に置く
2. Chromeで `chrome://extensions` を開く
3. 右上の「**デベロッパーモード**」をONにする
4. 「**パッケージ化されていない拡張機能を読み込む**」→ このフォルダを選択
5. claude.ai か gemini.google.com を開いてチャットすると、右下にメーターが出ます

## できること

- **右下の換算メーター(HUD)** — 「この会話 ¥◯」「今日 ¥◯」をチャット画面に常時表示。邪魔なときは「–」で折りたたみ、設定でOFFにもできます
- **ツールバーバッジ** — 今日の換算合計をアイコン上に表示
- **ポップアップ** — 今日・今月・累計、今月のモデル別内訳、直近7日間のグラフ、1件ごとの履歴
- **電卓** — モデル・トークン数・回数から料金を試算(円/ドル併記)
- **設定** — 表示通貨・為替レート・料金表の編集、Webアプリで使う既定モデルの指定
- **おまけ: API直呼びの記録** — ページ上のスクリプトが Claude / Gemini API を直接呼んだ場合も自動記録します

## 換算の仕組み(重要)

Webアプリの通信は読み取れないため、**画面上の会話テキスト量**から推定します。

1. メッセージ送信(Enter / 送信ボタン)を検知
2. **入力トークン** = その時点の会話全体+今回の発話を文字数から推定
   (実際のAPIでは毎回、会話履歴を丸ごと送り直すため。会話が長くなるほど1往復が高くなる、という実感が持てます)
3. **出力トークン** = 応答が止まるまでページのテキスト増分を監視して推定
4. モデルは画面上の表記(Opus / Sonnet / Pro / Flash など)から検出。検出できないときは設定の既定モデル(初期値: claude.ai → Sonnet 5、Gemini → 3.5 Flash)

トークン推定は「日本語≒1文字1トークン、英語≒4文字1トークン」の簡易計算です。

## 注意・既知の制限

- 表示される金額は**実際の請求額ではなく、API料金への換算値(概算)**です。Webアプリは定額・無料枠なので、実際に課金されるわけではありません
- プロンプトキャッシュ(実APIなら履歴部分が最大9割引になる仕組み)は考慮していないため、**やや高め(=緊張感が出る側)に出ます**
- 思考モードの推論トークン、画像・ファイル添付、Web検索分は数えられません
- 画面の構造に依存しない作りにしていますが、サイトの大幅なUI変更で検知精度が落ちる可能性はあります
- 料金表の初期値は2026年7月時点の各社公表値です。改定されたら設定タブで更新してください

## プライバシー

- 会話の本文・APIキーは一切保存しません(文字数から計算したトークン数のみ記録)
- データはすべて端末内(`chrome.storage.local`)にのみ保存され、外部送信はありません

## ファイル構成

| ファイル | 役割 |
|---|---|
| `manifest.json` | 拡張機能の定義(MV3) |
| `content.js` | claude.ai / Gemini上での会話計測とHUD表示 |
| `background.js` | 記録の保存・バッジ更新・API直呼びの監視 |
| `pricing.js` | 料金表の既定値とトークン推定ロジック(共有) |
| `popup.html / css / js` | ポップアップ(概要・履歴・電卓・設定) |
| `icons/` | アイコン |
